# EduLP Car — ขั้นตอนการทำงานและคู่มือตั้งค่า LINE

เอกสารนี้อธิบายลำดับการทำงานของระบบขอใช้รถราชการ ฝ่ายการศึกษา สำนักงานเขตลาดพร้าว
เมนูที่ใช้ในแต่ละขั้นตอน และวิธีตั้งค่ากลุ่ม LINE / แชทส่วนตัว

## 2. ความหมายของสีสถานะ

| สถานะ | สี | ความหมาย | ใครดำเนินการต่อ |
|---|---|---|---|
| `pending` | 🔵 ฟ้า | รอตรวจสอบคำขอ | หัวหน้าฝ่าย / Admin |
| `tentative` | 🟠 ส้ม | รอ ผอ.เขต อนุมัติ (นอกเวลา/นอกพื้นที่/วันหยุด) | ผอ.เขต / Admin |
| `approved` | 🟢 เขียว | อนุมัติแล้วและล็อกคิวรถ | Admin จัดสรรรถ/คนขับ |
| `rejected` | 🔴 แดง | ไม่อนุมัติ | ผู้ขอรับทราบ |
| `cancelled` | ⚫ เทา | ยกเลิกคำขอแล้ว | ทุกฝ่ายรับทราบ |

สีชุดนี้ใช้เหมือนกันทั้งเว็บแอปและข้อความ Flex Message ใน LINE

## 3. เมนูในเว็บและสิ่งที่ทำได้

### ผู้ใช้ทั่วไป
- **ปฏิทิน** — ดูตารางการใช้รถที่อนุมัติแล้วและรอ ผอ.เขต
- **ยื่นคำขอ** — กรอกแบบฟอร์มขอใช้รถ เลือกผู้ที่เกี่ยวข้อง และแนบข้อมูลเอกสาร
- **คำขอของฉัน** — ติดตามสถานะ ยกเลิกคำขอที่อนุมัติแล้ว และพิมพ์แบบ ๓

### Admin
- **คำขอใช้รถ** — กรองตามสถานะ ค้นหา ดูรายละเอียด อนุมัติ ไม่อนุมัติ แก้ไข จัดสรรรถ/คนขับ แจ้ง LINE
- **รถและคนขับ** — เพิ่ม/แก้ไข/ลบรถ (เลือกประเภทรถจากรายการมาตรฐาน) และพนักงานขับรถ
- **จัดการสมาชิก** — เพิ่ม/แก้ไข/ลบบัญชี และผูก LINE User ID
- **กลุ่ม LINE** — เพิ่ม/แก้ไข/ลบกลุ่ม ตั้งกลุ่มเริ่มต้น และคัดลอก Group ID
- **รายงานและจัดการข้อมูล** — ส่งออกรายงาน/ข้อมูล

### พนักงานขับรถ
- **ตารางขับรถ** — ดูงานที่ได้รับมอบหมายและงานที่กำลังจะถึง

## 4. ตั้งค่ากลุ่ม LINE (Group Chat)

1. เข้า LINE Developers Console → เลือก Messaging API Channel ของ OA `EduLP_Management`
2. เปิด **Allow bot to join group chats** (ค่าเริ่มต้นคือปิด)
3. ตั้ง Webhook URL เป็น
   `https://ccflyjycsfwnpfgkhpoy.supabase.co/functions/v1/line-webhook`
4. เปิด **Use webhook**
5. เชิญ OA เข้ากลุ่ม LINE ของฝ่ายการศึกษา
6. บอทจะตอบ Group ID กลับมา หรือพิมพ์ `/groupid` ในกลุ่ม
7. เข้าเว็บ → **จัดการระบบ → กลุ่ม LINE** → เพิ่มกลุ่ม หรือตรวจว่ากลุ่มถูกบันทึกอัตโนมัติแล้ว
8. กด **ตั้งเป็นกลุ่มเริ่มต้น** ให้กลุ่มที่ต้องการรับแจ้งเตือนหลัก

หลังตั้งค่า ระบบจะส่งข้อความเข้ากลุ่มเริ่มต้นโดยอัตโนมัติ โดยไม่ต้องแก้ secret `LINE_GROUP_ID` อีก

## 5. ตั้งค่าแชทส่วนตัว (Private Chat)

1. ผู้ใช้เพิ่มเพื่อน OA `EduLP_Management` ใน LINE
2. เข้าเว็บแล้วกด **เข้าสู่ระบบด้วย LINE**
3. ระบบจะบันทึก LINE User ID ลงโปรไฟล์ผู้ใช้
4. สำหรับพนักงานขับรถ: Admin ตรวจสอบใน **รถและคนขับ** ว่ามี LINE User ID แล้ว หรือให้คนขับล็อกอินเอง
5. ในคำขอใช้รถ เลือก **ผู้ที่เกี่ยวข้อง** จากรายชื่อที่ผูก LINE แล้ว (เมนูยื่นคำขอ/แก้ไขคำขอ)

> หากยังไม่มี LINE User ID ระบบจะแสดงรายชื่อผู้ที่ยังไม่ได้รับข้อความในผลการแจ้งเตือน

## 6. ตารางการแจ้งเตือน

| เวลา | ผู้รับ | รายละเอียด |
|---|---|---|
| ทุกวัน 16:00 น. | กลุ่มเริ่มต้น, คนขับ, ผู้เกี่ยวข้อง, ผู้ขอ | สรุปงานที่อนุมัติแล้วของวันถัดไป |
| ก่อนเริ่ม 30 นาที | พนักงานขับรถ | เวลา ปลายทาง รถ ผู้ขอ และเบอร์ติดต่อ |
| ก่อนเริ่ม 10 นาที | พนักงานขับรถ | แจ้งเตือนซ้ำก่อนออกรถ |
| ก่อนเริ่ม 10 นาที | ผู้ที่เกี่ยวข้อง | แจ้งเวลารถออก ปลายทาง และผู้ติดต่อ |

ระบบกันส่งซ้ำด้วยตาราง `trip_reminder_log` และตรวจทุก 5 นาทีผ่าน pg_cron

## 7. การพิมพ์แบบ ๓

- หลังยื่นคำขอสำเร็จ จะเห็นปุ่มสีเขียว **พิมพ์แบบ ๓ (A4)** เพียงปุ่มเดียว
- ปุ่มจะเปิดเอกสารในแท็บใหม่ เพื่อให้สั่งพิมพ์หรือบันทึกเป็น PDF
- เอกสารใช้เลขไทยและข้อความ “ในวันที่ / ถึงวันที่” ตามแบบราชการ

## 8. ข้อควรตรวจสอบเมื่อ LINE ไม่ทำงาน

| อาการ | สาเหตุ/วิธีแก้ |
|---|---|
| เชิญ OA แล้วออกจากกลุ่มทันที | ยังไม่เปิด **Allow bot to join group chats** |
| พิมพ์ `/groupid` แล้วไม่ตอบ | Webhook URL ไม่ถูกต้อง หรือยังไม่เปิด Use webhook |
| ขึ้นว่าเซสชัน LINE หมดอายุ | กด **เข้าสู่ระบบด้วย LINE** ใหม่ ระบบจะขอ ID token สด |
| ไม่มีข้อความเข้ากลุ่ม | ยังไม่ได้ตั้งกลุ่มเริ่มต้นในเมนู **กลุ่ม LINE** และไม่มี `LINE_GROUP_ID` สำรอง |
| คนขับไม่ได้รับข้อความ | คนขับยังไม่ผูก LINE User ID หรือยังไม่ได้เพิ่มเพื่อน OA |
| ผู้เกี่ยวข้องไม่ได้รับ | ยังไม่ได้เลือกผู้ที่เกี่ยวข้อง หรือผู้ใช้นั้นยังไม่ผูก LINE |
